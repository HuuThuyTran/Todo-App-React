# 📝 Todo App (React)

A simple and clean Todo List application built with **ReactJS** to manage daily tasks efficiently. This project demonstrates fundamental React concepts and modern UI/UX practices.

---

## 🚀 Features

* ➕ Add new tasks
* ❌ Delete tasks (with confirmation)
* ✅ Mark tasks as completed
* 🔼🔽 Move tasks up/down
* 🔔 Toast notification after deleting
* 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

* ⚛️ ReactJS
* 🎨 CSS (custom styling)
* 🎯 React Icons
